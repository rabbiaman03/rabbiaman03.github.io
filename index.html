01 // about

Security mindset, hands-on practice

I study cybersecurity with a focus on defending real networks and cloud identity systems. Every lab is built in an isolated environment and documented with a written report and evidence.

I am especially interested in how LLM agents can speed up log analysis and security operations, and how to do that safely with permission gates and clear limits.

01

Least privilege

Give every user, app and agent only the access it needs.

02

Defense in depth

Layer network, identity and application controls so one failure is not a breach.

03

Verify, then trust

Zero Trust thinking: check identity and device on every request.
