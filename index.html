Hi, I'm Rabbi Muhammad Aman. I study how systems fail, then build them so they hold.

I'm a cybersecurity student at Seneca Polytechnic in Toronto, working across network security, cloud identity and web application security. I like the moment a scan, a log or a packet capture turns into a finding, and the moment after, when the fix ships.

I build lab networks in VMware, automate hardening with Ansible, write tools in Python and Bash, and use AI agents to speed up log analysis. Every lab I finish is documented on GitHub. I'm looking for a co-op or internship in security analysis, network security or SOC work.
